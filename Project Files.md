# Project Resources

Due to GitHub's file size limitations, the complete project resources have been organized and stored in a Google Drive folder.

## Google Drive Folder Structure

### 📂 Dataset
Contains the original Instacart dataset used for the project.

Files:
- aisles.csv
- departments.csv
- order_products__prior.csv
- orders.csv
- products.csv

### 📂 Final Dataset
Contains the cleaned and transformed datasets generated during data preprocessing.

Files:
- instamart_final.csv
- market_basket_rules.csv
- market_basket_rules_clean.csv

### 📂 Python Code
Contains the Python scripts used for data preprocessing, data merging, and market basket analysis.

Files:
- cleaning.py
- merging.py
- market_basket.py
- marketbasket.py
- clean_rules.py

### 📂 Quick Commerce Analytics Dashboard
Contains the Power BI dashboard file.

Files:
- Quick Commerce Analytics.pbix
